# Nginx WebUI 1.1.3

**发布日期**：2026-10-02

## 新增与改进

- 新增管理员专用的阿里云 DNS 配置页面，可保存目标域名及 RAM AccessKey，并测试 DNS 查询、TXT 添加和删除权限。Secret 保存在持久化数据目录的私有文件中，读取接口不会回传。
- 证书申请支持阿里云 DNS 自动验证，可一次签发主域名和泛域名证书。Certbot 自动创建、等待生效并清理本次的 TXT 记录，续期时复用保存的 hook。
- 已上传的同名证书可重新签发并接管为自动续期证书；签发失败时保留现有证书记录。

## 问题修复

- 修正固定 TXT 记录和手动 DNS 验证无法无人值守续期却可能显示“自动续期”的问题。
- 续期任务逐张处理证书，记录失败原因；证书更新后同步持久化文件并重载 Nginx。
- DNS 传播等待改为检查域名的权威 DNS，避免公共递归解析器缓存旧 TXT 导致误判超时。

## 升级说明

1. 重新构建并部署前后端镜像，保留 `/app/data` 数据卷。
2. 在“证书 DNS 配置”填写阿里云托管的主域名及 RAM AccessKey。RAM 权限至少包括目标域名的解析记录查询、添加和删除。
3. 点击“测试 DNS 读写权限”，再到证书管理页选择“阿里云 DNS 自动验证”申请。原先上传或手动 DNS 签发的证书需要重新签发一次，才能启用自动续期。
4. 对已有 Certbot 记录可执行 `certbot renew --dry-run --cert-name <证书名>` 验证无人值守续期。

## 兼容性

无数据库结构变更。阿里云凭据文件保存在 `/app/data/letsencrypt/aliyun-dns.json`，请随数据卷一同保护和备份。
