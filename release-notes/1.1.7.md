# Nginx WebUI 1.1.7

**发布日期**：2026-11-06

## 更新内容

- 内置 Nginx 主线版本升级至 **1.31.8**，包含 1.31.2 之后的安全修复。初始化向导按实际内置源码包确定编译版本。
- 通过 WebUI 编译的 Nginx 默认省略 HTTP `Server` 响应头，默认错误页保留对应状态码和提示。登录后仍可查看实际运行版本。
- 新安装默认关闭公开目录索引，WebUI 仍支持站点目录浏览、编辑、上传和下载。整个 Nginx 安装目录、配置上线和版本切换由管理员操作。
- 初始管理员使用随机密码。新增登录失败限制和审计，修改密码后原会话失效。管理端 API 文档默认关闭。
- 受 WebUI 管理的本地访问日志、错误日志和操作日志至少保留 185 天。

## Docker 升级

1. 备份持久化的 `/app/data`，继续使用原数据卷和端口映射。镜像为 `registry.cn-shanghai.aliyuncs.com/numen/nginx-webui:1.1.7`。
2. 拉取镜像并重新创建 WebUI 容器。升级后重新登录，使用 Bearer Token 的脚本也需获取新令牌。仍使用 `admin/admin` 的部署可在数据目录下的 `backend/initial-admin-password` 读取新密码。
3. 在 **Nginx 管理** 编译内置的 1.31.8，测试配置，发布到运行版并重启 Nginx。已有运行版会在 WebUI 镜像升级时继续运行，可自行安排切换窗口。
4. 用站点的正常页和真实错误页检查响应，再登录 WebUI 确认运行版本、文件管理和日志均正常。
